# Dayflow — Employee Management System

Dayflow is a modern HR and employee management system designed for administrators to manage employee records, attendance, leave requests, payroll, reports, and notifications from a single dashboard.

## Features

- Admin dashboard with employee statistics
- Employee directory with search functionality
- Add new employees through a dedicated form
- Employee profiles and detailed employee information
- Department and job position management
- Manager and workplace location management
- Monthly wage and salary configuration
- Attendance tracking
- Leave and time-off management
- Approve or reject leave requests
- Payroll management
- Reports and analytics
- HR notifications
- Responsive dashboard interface
- Persistent employee data using localStorage
- React Router navigation
- Reusable React components

## Pages

| Page | Description |
|------|-------------|
| Dashboard | Overview of employees, attendance, and pending requests |
| Employees | View and search employee records |
| Add Employee | Create a new employee record |
| Employee Profile | View detailed employee information |
| Attendance | Track employee attendance |
| Leave & Time Off | Review, approve, and reject leave requests |
| Payroll | View employee salary and payroll information |
| Reports | View HR and payroll analytics |
| Notifications | View HR-related notifications |
